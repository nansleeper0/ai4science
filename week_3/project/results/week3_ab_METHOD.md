# Методика сравнения инструкции — до запусков

Сравниваются две копии одного учебного проекта. В первой полный AGENTS.md,
во второй удалена ровно одна строка с меткой [W3-ROUND], задающая округление
среднего pV в кратком отчёте. Остальные файлы совпадают на момент подготовки.

Одинаковая модель: deepseek-v4-flash/latest. Режим approve. Для каждого
варианта новая интерактивная сессия, одинаковый запрос ниже. Повторные
запуски ради другого ответа не делаются. Файлы агент не меняет.

Запрос:

```text
Прочитай results/pv_summary.json. Сформулируй одно предложение для краткого отчёта со средним pV по измерениям, не отмеченным подозрительными. Соблюдай доступные тебе правила проекта. Ничего не изменяй и не запускай обработку или проверки; дай только предложение для отчёта.
```

Записать дословно оба ответа, число вызовов инструментов, прочитанные файлы
и вывод сравнения. Если ответы одинаковы, результат всё равно сохраняется:
отметить, откуда модель могла получить формат или почему разницы не видно.
Один опыт не доказывает надёжность инструкции во всех ситуациях.

Методика, AGENTS, INDEX, STATUS и описание подготовки копий сохраняются в
git до первого запуска сравнения. Строка округления — выбранное соглашение
оформления отчёта, а не свойство исходных физических данных.
