## 2026-11-01 — Доработка и проверка результатов

После разбора первоначального результата я повторно запустил учебного
агента для исправления вывода IQR и уточнения отчёта. В доработанном
коде IQR вычисляется как разность Q3 − Q1. Для используемого метода
квартилей это 251,8356 − 247,036 = 4,7996, или 4,800 после округления.
Прежнее значение 19,198 соответствовало ширине интервала между
границами обнаружения выбросов, а не самому IQR.

Для независимой проверки использован предоставленный скрипт
check_boyle.py. Его вывод сохранён в results/verification.txt.
Проверка отметила строку №7 как подозрительную. Для остальных
наблюдений получены среднее pV около 249,3 кПа·л и относительный
разброс около 1,1%. Код завершения 1 соответствует обнаруженной
подозрительной строке и является ожидаемым результатом.

Причина отклонения строки №7 пока не установлена. Для её выяснения
необходимо проверить происхождение данных и единицы давления.
Исходный CSV сохранён без изменений. Статистика остальных
11 наблюдений характеризует выбранную часть данных и сама по себе
не доказывает выполнение физического закона.
