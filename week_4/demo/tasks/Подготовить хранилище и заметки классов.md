# Подготовить хранилище и заметки классов

Готово, когда: существуют .obsidian/app.json и .obsidian/graph.json, для каждого класса из ontology.yaml есть заметка ontology/<Класс>.md.
Не входит: изменение ontology.yaml.

## Итог
Созданы .obsidian/app.json и .obsidian/graph.json, каталоги проекта; для всех 15 классов ontology.yaml созданы заметки ontology/<Класс>.md скриптом src/make_class_notes.py (запуск: python3 src/make_class_notes.py, код 0). Закрыто заметкой notes/Подготовка хранилища и заметок классов.md.

Принято пользователем: «Проверку принимаю с замечанием: первая сессия использовала 45 инструментальных шагов при бюджете 40. Сохрани это замечание при записи приёмки.»
