# Модель LS1997 shot-noise

Апериодическая переменность описывается суперпозицией одинаковых шотов (shot noise); шоты модулируются периодическим сигналом через параметр связи C (умножение, а не сложение). В степенном спектре модуляция даёт широкие крылья вокруг узких пиков периодического сигнала (терм c формулы 5).
