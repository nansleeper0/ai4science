Каталоги notes/, tasks/ и ontology/ относятся к исследовательскому графу; это обязательные артефакты проекта.

В работах использовался учебный агент AI4Science (Goose). Исходные ответы, неудачные попытки, результаты проверок и замечания о превышении бюджета сохранены в журналах. Проверка структуры графа не заменяет научную и человеческую приёмку.

## Просмотр и проверки

Для вычислений недели 2 достаточно Python 3 и стандартной библиотеки:

```bash
cd week_2/project
python3 checks/check.py
```

Проверка недели 3 использует pypdf. Для проверок графов требуется PyYAML:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pypdf PyYAML

python week_3/project/verify_week3_local.py
(cd week_4/demo && python check_week4.py --strict)
(cd week_4/project && python check_week4.py --strict)
(cd week_5/project && python check_week4.py --strict)
```

В `week_2/runs/run_with` проверка пиков проходит. В `run_without` сохранён неуспешный опыт: отсутствие results/peaks.csv и код 1 — фактический результат сравнения.

Notebook открываются в Jupyter; рабочая папка ядра — соответствующий notebooks/. Сохранённые результаты можно читать без повторных обращений к моделям и внешним API. Зависимости и параметры поиска записаны в notebooks/search_METHOD.md и library/search_provenance.json недели 5. Повторное выполнение поисковых и агентских ячеек требует отдельной настройки среды и доступа к сервисам.

Для графа Obsidian следует открыть как хранилище папку week_4/demo, week_4/project или week_5/project. Версии и контрольные суммы статей указаны в library/catalog.csv; исходные PDF и тексты, необходимые графу, включены в снимки недель 4–5.

## История публикации

Сохранена ранняя история практик и методика сравнения, зафиксированная до запусков. Из истории публикации исключены служебные резервные файлы подготовки недели 3; поэтому соответствующий коммит получил новый идентификатор. В опубликованном verify_week3_local.py изменена только ссылка на этот коммит. Исходный идентификатор и записи эксперимента сохранены без изменения. Вычислительные правила и критерии проверки сохранены.

Исторические абсолютные пути в сырых сессиях и выводе notebook относятся к исходной рабочей машине. Личные планы занятий, окружения, ключи и служебные материалы подготовки в репозиторий не включены.
